> ## 5. Geofencing
>
> The assigned Site becomes the source of truth for the employee's geofence.
>
> For Guards:
>
> * Fixed radius: **100 meters**
> * Use Android device-side location/geofencing capabilities.
> * Do NOT continuously send GPS coordinates to the server.
> * Do NOT make API requests for every location update.
> * Trigger the relevant server event only when the guard crosses outside the 100m boundary.
> * Prevent repeated exit events while the guard remains outside.
> * Update local geofence state when the guard returns inside.
> * Handle permission denial, location services disabled, battery restrictions and unavailable location gracefully.
> * Never crash because location permission is unavailable.
>
> Do not implement continuous server-side GPS tracking.
>
